Protect the private key

Never upload the private key to GitHub, send it to Copilot, or paste it into ChatGPT. This page does not transmit either key to a server or external service.

Download the private key and back it up securely. If it is lost, the encrypted inspection artifact cannot be decrypted. Anyone who obtains the private key may be able to decrypt artifacts encrypted for its matching public key.

This utility is independent of Cloudflare credentials and production systems. It does not request or use a Cloudflare token.

Use a browser that supports Web Crypto RSA-OAEP. If opening this file directly does not provide crypto.subtle, use a trusted local secure context. Do not upload the private key to make the page work.
